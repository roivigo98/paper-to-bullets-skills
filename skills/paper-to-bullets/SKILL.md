---
name: paper-to-bullets
description: "Turn a paper into five bullets: title, question, method, result, limitation. Use when the user shares a paper or asks to triage one."
---

Read the file the user names, then output exactly these five bullets and nothing else:

- **Title:** the paper's title
- **Question:** the research question it asks
- **Method:** how it answers that question
- **Result:** the main finding
- **Limitation:** the most important limitation
